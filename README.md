# The Mansion Mewgenics Custom Area
Brand new custom area for Mewgenics.\
There is a new map icon at the end of The Alley which leads to The Mansion, a brand new area including new enemies and probably too many vampires.\
Currently being worked on, as of right now only 1 enemy has been added, and many of the visuals are WIP.
